ⓘ About ECHO RULE

How to playWatch the highlighted cells during the preview. When they disappear, select the same cells. Selecting a selected cell again removes it. Press SUBMIT to check your answer.
HintsHINT is optional. Missing cells are revealed one at a time; extra selections are reported as blocks to remove. On order stages, HINT can identify the first wrong position. Advanced stages may include dim decoy flashes; only the bright memory pattern matters.
ScoringThree stars reward a clean solve with no hints and few attempts. Best completion times are stored per level.
ControlsMouse or touch: select and deselect cells. Keyboard: Enter activates SUBMIT, H toggles HINT, R resets the level, P pauses.
Game modesNormal builds progression, Daily Memory changes each day, Endless keeps increasing, Zen removes time pressure, and Timed Challenge adds a countdown.
Original gameECHO RULE is an original browser puzzle focused on memory, precision and gradually increasing challenge.

🎮 More Modes

Choose a run from the lobby: play the Daily Memory, keep climbing in Endless, relax in Zen, or race the clock in Timed mode.
